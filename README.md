# Lafeli Beauty

Website for Lafeli Beauty, a home studio in Willaston, near Nantwich, Cheshire, offering lymphatic drainage, massage, waxing, nails and brows. Built with [Astro](https://astro.build), with online booking through Fresha and enquiries via WhatsApp.

Pages: Home, Pricing (treatments), About, Testimonials and Contact.

## Run the site

```sh
nvm use 22
npm install
npm run dev
```

The dev server runs at `http://localhost:4321`.

| Command           | Action                                  |
| :---------------- | :-------------------------------------- |
| `npm run dev`     | Start the local dev server              |
| `npm run build`   | Build the production site to `./dist/`  |
| `npm run preview` | Preview the production build locally    |
